第 3 小时 · 数学与工程基础（二）· 预测决策与工程伦理

本学时覆盖 2.3 预测与决策 + 2.4 数学建模 + 2.5 工程伦理，并附全章易错辨析 + 速记卡 + 自测清单。
2.5 工程伦理是每年送分题，务必拿稳；不确定型五准则是本章计算题的另一半。

考情定位

四块必拿：① 不确定型决策五准则（乐观 max-max / 悲观 max-min / 折中 α / 后悔值 Savage / 等可能 Laplace）；② 指数平滑（α 越大越灵敏）；③ 线性规划图解法（最优解在顶点）；④ 工程伦理第一原则（公众安全健康福祉首位）。

记忆口诀

五准则：乐观好中求好｜悲观坏中求好｜折中α 加权｜后悔值 = 先算后悔矩阵再"最大后悔中取最小"｜等可能取平均最大。
指数平滑：`F(t+1) = α·A(t) + (1−α)·F(t)`，α 大 → 灵敏，α 小 → 平滑。
决策四阶段（Simon）：情报 → 设计 → 选择 → 实施。
建模七步：准备 → 假设 → 建立 → 求解 → 分析 → 检验 → 应用（假设在建之前）。

易错陷阱

后悔值准则最容易混——关键是先构造后悔矩阵（后悔值 = 该状态下最优收益 − 本方案收益），再在"各方案的最大后悔值"里取最小的，不是直接比收益。
建模七步里"假设"必须在"建立"之前——先有简化前提才谈得上建关系式。
工程伦理题的陷阱通常是"按老板要求隐瞒风险"——正确做法是如实报告风险，公众安全优先于雇主指令。

论文可用句

在工期估算上，我未采用单点估算，而是用 PERT 三点估算：对每个活动给出乐观、最可能与悲观三个工期，按 `(O+4M+P)/6` 计算期望，并按 `(P−O)/6` 计算标准差评估风险；据此识别出关键路径上的 3 个高风险活动，为它们各预留了 15% 的缓冲，最终项目实际工期与计划偏差控制在 4% 以内。

第 2 章知识骨架

2.3 预测 · 三途径 + 七区域 ⭐

🔮科学预测的三种途径

① 因果分析研究事物的形成原因来预测未来发展的必然结果

② 类比分析把发展中的事物同历史上的"先导事件"相类比（如单项技术发展类比生物增长）

③ 统计分析运用数学方法分析过去和现在的数据，由表及里揭示规律

⭕系统 S · 模型 M · 结论 C 三圆七区域 ⭐

三个圆相交分出 7 个区域代表预测的 7 种情况：

  • S∩M∩C：正确的模型对系统做出科学预测（唯一追求）
  • S∩M∩C̅：错误地解释了模型运行结果
  • S∩M̅∩C：错误的模型碰巧获得正确结论
  • S∩M̅∩C̅：错误的模型和结论
  • 其余 3 种 = 系统分析错误导致的盲目建模/预测

其他 6 种皆存在信息失真，应尽可能避免

2.3.2/2.3.3 预测程序与指数平滑法 ⭐

🪜预测程序（六步）

①明确预测任务、制订预测计划（无明确目的就会迷失方向）

②搜集、审核和整理资料——筛选三标准：直接有关性 · 可靠性 · 最新性

③选择预测方法和建立数学模型（资料不全→定性；资料齐全→定量）——提高预测准确性的关键步骤

④检验模型（理论合理 · 统计可靠 · 预测能力强 · 简单适用）

⑤分析预测误差、评价预测结果

⑥向决策者提交预测报告（说明假设前提、方法、合理性依据）

📉一次指数平滑法 ⭐（教材例题）

ŷ₍ₜ₊₁₎ ＝ α·yₜ ＋ (1−α)·ŷₜ

yₜ = t 期真实值；ŷₜ = t 期预测值；α = 平滑系数，α∈(0,1)

α 的含义α 越大 → 越敏感（对近期数据变化反应越快）；α 越小越平滑

初始值常取 S₀ = (y₁ + y₂) / 2

例（教材）α=0.3 时平均相对误差 3.41%；α=0.8 时 3.97% → 误差小者胜 → 选 α=0.3

其他方法机器学习算法（线性回归/决策树/随机森林/神经网络）· 模拟 · 主观判断（专家经验）

⚠️ 方法选择：资料不够全/准确度低 → 定性（德尔菲法、专家调查）；资料齐全准确高 → 定量（时间序列 / 因果回归）。

2.3.4/2.3.5 决策四阶段 + 不确定型五准则 ⭐⭐

🪜决策过程四阶段

① 情报活动识别问题、理解问题，设定决策目标（决策时机选择）

② 设计活动寻求多种途径确定备选方案——强调多方案（只有一种方案就无所谓决策）；含状态分析与后果预测

③ 抉择活动预估各方案后果，做出结论性评价，选出最满意方案

④ 实施活动实施选定方案，跟踪、监督、反馈，检查或修正原决策

💡 决策是动态过程，后面阶段不断向前面的阶段反馈信息。

🎲不确定型决策五准则 ⭐⭐（必考辨识）

准则别称 / 提出者选择逻辑
① 乐观max-max每个方案取最大收益，再从中取最大（好中选好）
② 悲观max-min（瓦尔德 Wald）每个方案取最小收益，再取最大——"最坏中取最好"
③ 折中赫尔维茨 Hurwiczα×最大收益 + (1−α)×最小收益，取最大（α = 乐观系数）
④ 等可能拉普拉斯 Laplace各状态概率相同，取期望值最大
⑤ 后悔值萨维奇 Savage（min-max regret）先构造后悔矩阵（最大收益 − 该状态收益），再取最大后悔值中的最小 ⭐

⚠️ 最爱考的两句："后悔值最小"＝萨维奇准则；"最坏中取最好"＝悲观准则（瓦尔德）。

💡 风险型决策（已知概率）→ 用期望值或决策树；贝叶斯决策 = 用新信息修正先验概率 → 后验概率。

2.3.5 线性规划 · 图解法例题 ⭐（教材原题）

📐题目（工厂生产计划）

工厂计划期安排生产 Ⅰ、Ⅱ 两种产品（Ⅰ 获利 2 元/件，Ⅱ 获利 3 元/件），资源限制如下：

  • 设备：Ⅰ 需 1 台时、Ⅱ 需 2 台时，共 8 台时
  • 原料 A：Ⅰ 需 4kg，共 16kg
  • 原料 B：Ⅱ 需 4kg，共 12kg

问如何安排生产使利润最大？

标准形式 = 目标函数 + 线性约束 + 变量非负

  • 目标函数：max z = 2x₁ + 3x₂
  • 约束条件：x₁+2x₂ ≤ 8　4x₁ ≤ 16　4x₂ ≤ 12　x₁,x₂ ≥ 0

✏️图解法四步（逐步）

① 画可行域各约束代表一个半平面；同时满足所有约束的点集 = 可行域（有界/无界凸多边形）

② 画等值线目标函数 z = 2x₁+3x₂ 是一组平行线（斜率 −2/3）；同一直线上 z 值相同

③ 平移求极值z 由小变大，直线沿法线方向移动；移动到可行域边界顶点 Q₂ 时 z 最大

④ 解顶点坐标Q₂ = (4, 2) → z = 2×4 + 3×2 = 14 元

结论生产 4 件Ⅰ、2 件Ⅱ，最大利润 14 元

⚠️ 重要结论：若线性规划存在最优解，一定在可行域的某个顶点得到（两个顶点同时最优 → 连线上都是 → 无穷多解）。

异常情况：无界解 = 缺少必要约束；无可行解 = 约束条件矛盾（都说明模型有错误）。变量 >3 个用单纯形法（从可行域顶点转到更优顶点）。

💡建模的特点与意义

逼真性与可行性折中——越逼真越复杂，越可行越简化；假设简化是建模的核心手段

渐进性建模是逐步逼近、不断迭代的过程，很少一次成功

强韧性（健壮性）模型在条件变化时仍能保持结论基本可靠

迁移性模型可跨界复用（同一数学模型用于不同领域）

意义是现实问题与数学工具之间的桥梁——应用于一般工程技术、高新技术、交叉学科三大领域

口诀：白灰黑箱分机理，七步走完才建模；逼真可行做折中

2.5 工程伦理 ⭐（每年送分题）

⚖️技术与工程的区别（4 方面）

① 内容性质技术以发明为核心；工程以建造为核心

② 成果类型技术成果 = 发明、专利、技能（有"产权"的私有知识）；工程成果 = 物质产品、物质设施

③ 活动主体技术 = 发明人；工程 = 工程师及工人、管理者、投资方

④ 任务思维技术求普遍性可重复性；工程是相对独立完整的活动单元（独一无二）

❗四大工程伦理问题

技术伦理（技术运用需道德评判）· 利益伦理（公平协调各方利益）· 责任伦理（事前责任与决策责任）· 环境伦理（可持续发展的必由之路）

💡 责任观演变：忠诚责任 → 社会责任 → 自然责任。

📜处理工程伦理问题的三原则（教材）⭐

  • ① 人道主义（工程与人）：含自主原则（人格平等；必要条件：保护隐私 + 知情同意）与不伤害原则（尊重生命，"安全第一"是道德底线）
  • ② 社会公正（工程与社会）：群体的人道主义——兼顾强势/弱势群体、受益者/利益受损者等各方利益；保障生存权、发展权、财产权、隐私权
  • ③ 人与自然和谐（工程与自然）：遵从自然规律（物理化学，因果确定）与生态规律（长期性、复杂性、难挽回）
  • 总纲：工程伦理要"将公众的安全、健康和福祉放在首位"（欧美工程社团章程第一条款；NSPE / IEEE / ASCE 皆如此）。

责任的微观层面（工程师个人：诚实正直）与宏观层面（职业与社会：社会责任）。

口诀：人道（自主不伤害）、公正、人与自然；公众安全放首位

全章速记卡 · 考前 5 分钟

🧮公式卡（必背）

  • 古典概型 P = 有利事件数 / 总事件数（有限+等可能）
  • E(X) = Σxᵢpᵢ；D(X) = E(X²) − [E(X)]²；σ = √D(X)
  • E(aX+b) = aE(X)+b；D(aX+b) = a²D(X)（b 不影响方差）
  • 二项 E=np, D=np(1−p)；泊松 E=D=λ；指数 E=1/λ
  • 正态 3σ：±1σ 68.3% / ±2σ 95.4% / ±3σ 99.7%
  • 生成树边数 n−1；Prim O(n²) 稠密；Kruskal O(e·log₂e) 稀疏
  • Dijkstra 单源非负；Floyd 全对 O(n³)；Bellman-Ford 负权+检负环 O(nm)
  • 最大流 = 最小割（Ford-Fulkerson 增广路）
  • 关键路径 = 最长路径；总浮动 = LS−ES = LF−EF
  • PERT：t=(a+4m+b)/6；σ=(b−a)/6
  • 指数平滑 ŷ₍ₜ₊₁₎ = α·yₜ + (1−α)·ŷₜ

  • 最小生成树 4 种算法：Prim · Kruskal · Boruvka(可并行) · 反向删除

🔗对应关系卡

  • 稀有事件计数 → 泊松分布（E=D=λ）
  • 可靠性/寿命（无记忆） → 指数分布
  • 大量测量误差 → 正态分布；n 次独立重复 → 二项分布
  • 稠密图 → Prim；稀疏图 → Kruskal；大规模可并行 → Boruvka
  • 单源非负 → Dijkstra；所有点对 → Floyd；负权边 → Bellman-Ford
  • 网络吞吐/运输调度/二分匹配 → 最大流
  • 压缩工期：赶工(增成本) / 快速跟进(增风险)
  • 资料不全 → 定性预测(德尔菲)；资料齐全 → 定量预测
  • 无界解 = 缺约束；无可行解 = 约束矛盾（模型有误）
  • 保护隐私 + 知情同意 → 自主原则的必要条件

⚖️对比卡

  • Prim（点/树/O(n²)/稠密） vs Kruskal（边/森林/O(e·log₂e)/稀疏）
  • Dijkstra（单源/非负） vs Floyd（全对/DP） vs Bellman-Ford（负权/检负环）
  • 关键路径 = 最长（不是最短！）；总时差 0 = 关键活动
  • 乐观 max-max vs 悲观 max-min（瓦尔德） vs 折中（赫尔维茨） vs 等可能（拉普拉斯） vs 后悔值（萨维奇）
  • 定性预测（德尔菲） vs 定量（时间序列/因果回归）
  • 白箱（机理清楚） vs 灰箱 vs 黑箱（数据驱动）
  • 技术（发明/专利） vs 工程（建造/物质产品）

1不确定型决策的五种准则中，"先找出每个方案的最大后悔值，再从中选最小的"这一准则是：
A后悔值准则（最小最大后悔值 / Savage 准则）
B乐观准则（max-max）
C悲观准则（max-min / Wald 准则）
D等可能准则（Laplace）
不确定型决策五准则：① 乐观准则（max-max）——"好中求好"，先取每方案最大收益，再取最大；② 悲观准则（max-min，Wald）——"坏中求好"，先取每方案最小收益，再取最大（保守）；③ 折中准则（Hurwicz）——用乐观系数 α 加权：α×最大 + (1−α)×最小；④ 后悔值准则（Savage，最小最大后悔值）——先算后悔矩阵（后悔值 = 该状态下最优收益 − 本方案收益），再"最大后悔值中取最小"；⑤ 等可能准则（Laplace）——假设各状态概率相等，取收益平均值最大的方案。
第2章 · 2.3.5 不确定型五准则
2指数平滑法中，平滑系数 α 的取值大小对预测结果的影响是：
Aα 越大越重视近期实际值、预测越灵敏；α 越小越平滑、越稳定
Bα 越大越平滑
Cα 与预测灵敏度无关
Dα 只能取 0.5
一次指数平滑公式：F(t+1) = α·A(t) + (1−α)·F(t)，其中 A(t) 是第 t 期实际值，F(t) 是第 t 期预测值。α 越大 → 越看重近期实际值，预测对新变化反应灵敏但波动大；α 越小 → 越依赖历史预测，曲线更平滑稳定但对变化反应迟钝。经验取值：数据平稳取 0.1~0.3，数据波动大取 0.6~0.8。⚠️ 这是本章最典型的"给 α 问含义"题。
第2章 · 2.3.3 指数平滑法
3线性规划图解法中，最优解的位置一定出现在：
A可行域的顶点（极点）上，或在某条边界线段上
B可行域的中心
C目标函数的中点
D坐标原点
线性规划的基本结论：若存在最优解，则一定可以在可行域的某个顶点（极点）上达到；若目标函数与某条边界平行，则该边界线段上的所有点都是最优解（无穷多最优解）。图解法步骤：① 画约束条件确定可行域；② 画目标函数等值线；③ 沿法方向平移等值线到极限位置，最后接触到的顶点即最优解。

5关于工程伦理，下列说法正确的是：
A工程师应将公众的安全、健康和福祉放在首位
B只需对雇主负责，公众安全不在考虑范围
C只要不违法，伦理问题可以忽略
D伦理准则只在出现事故后才需要
工程伦理首要原则：将公众的安全、健康和福祉放在首位（这是各类工程师伦理守则的第一条，NSPE、IEEE-CS/ACM 软件工程伦理均如此）。其余要点：诚实守信（不弄虚作假、如实报告风险）、胜任（只承接能力范围内的工作）、忠诚与保密（对雇主/客户）、公平（不歧视、不贿赂）、可持续发展（对环境负责）。⚠️ 本章是每年送分题，题干常设置"按老板要求隐瞒风险"这类陷阱。
