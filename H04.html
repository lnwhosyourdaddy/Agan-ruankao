H04 计算机系统（一）· 硬件与体系结构 1 / 26

第 4 小时 · 计算机系统（一）· 硬件与体系结构

第 3 章真题占比 13.1%（73/557）—— 全教材第二大章，仅次于第 7 章软件工程（19.6%）。
本学时覆盖 3.1 三级层次 + 3.2 存储器系统 + 3.3 I/O 与总线 + 3.4 指令系统 + 3.5 多处理机。
硬件与体系结构部分是计算题集中营（Cache 平均访问时间、RAID 容量、流水线效率）。

考情定位

四块必拿：① 冯·诺依曼五部件（运算器+控制器=CPU）；② 存储器层次（速度/容量/价格三反）；③ Cache 平均访问时间计算（加权平均是必考公式）；④ CISC vs RISC 五维度对比 + 多处理机紧/松耦合。

记忆口诀

存储器层次三反：越靠上越快、小、贵；越靠下越慢、大、便宜。
Cache 平均访问：`h·t_c + (1−h)·t`，命中率高才能体现 Cache 价值。
CISC / RISC 一句话：CISC 指令多而杂（微程序、长度可变），RISC 指令少而精（只有 load/store 访存、长度固定、好流水线）。
多处理机：紧耦合共享主存（SMP）、松耦合分布式主存（MPP）。

易错陷阱

「阻塞态不能直接回到运行态」——必须先回就绪态排队，这是操作系统最高频的易错点。
多处理机两维度别混：按存储方式分紧/松耦合；按共享方式分 SMP/MPP/S2MP。问"主存是否共享"就是在问紧/松耦合。
RAID 各级别（0/1/5/6/10）必背，容量与可靠性计算题年年出现。

第 3 章上集知识骨架

3.1 计算机系统的三级层次结构

🏛️教材口径：三级层次

通常可划分为包括硬件层、系统层和应用层的多级层次结构。

① 硬件层（裸机）

再细分三级：硬联逻辑级（门电路/触发器，计算机内核）→ 微程序级（机器语言是微指令集）→ 传统机器级（机器语言是本机指令集）

② 系统层

操作系统级（管理软硬件资源）＋ 语言处理程序级（编译/汇编/解释，把高级语言翻译成机器语言）

③ 应用层

面向不同用户的各种应用程序

🧱虚拟机 与 固件（易考小点）

虚拟机：在裸机上层层扩充形成的、功能更强大也更易使用的机器。每一层都为上一层提供支撑。

💾固件 Firmware

存储在能永久保存信息的器件（EPROM / EEPROM）中的程序，是具有软件功能的硬件。

  • 通过固件，操作系统才能按标准设备驱动程序实现特定机器的运转
  • 性能指标介于硬件与软件之间：执行速度快于软件，灵活性优于硬件

⚠️ 考点：固件"介于软硬件之间"这个定性描述，选择题直接考原话。

3.1.2 冯·诺依曼体系结构 · 五个基本部件

✅ 冯·诺依曼体系结构的核心：基于存储程序的原理 —— 指令与数据同等存于存储器，按地址访问，用二进制表示。硬件由 5 个基本部分组成：运算器、控制器、存储器、输入设备、输出设备。

部件归类（易考）：运算器＋控制器 ＝ CPU（硬件系统核心，数据加工处理，完成算术/逻辑运算及控制）；输入设备＋输出设备 ＝ 外部设备（外设）；存储器分内存储器（速度快容量小，临时存放）和外存储器（容量大速度慢，长期保存）。

3.1.3 软件分类 与 3.2 存储器系统总览

🧩软件两大类

系统软件（管理、调度、监视、服务），分 5 类：

① 操作系统　② 语言处理程序

③ 服务性程序　④ 数据库管理系统

⑤ 计算机网络软件

应用软件：为解决某种应用问题而编制的程序（财务/项目/营销管理软件等）。

🗄️存储器系统 · 三级层次（由快到慢、由贵到便宜）

4 种存取方式

顺序存取（磁带）· 直接存取（磁盘）· 随机存取（主存）· 相联存取（按内容）

4 个性能指标

存取时间 · 存储器带宽 · 存储器周期 · 数据传输率

教材原话：传统存储器系统一般分为 Cache、主存储器、辅助存储器 三级。靠的是程序访问的局部性。

3.2.1 主存 与 3.2.2 辅存 · 分类速览

⚡主存储器（内存）

作用：存放运行时的程序和数据，CPU 可直接随机读写。

RAM 随机存取存储器

可读可写，断电后信息无法保存，只能暂存。

  • DRAM 动态：信息会随时间消失，需定时刷新
  • SRAM 静态：不断电就一直保持，不需刷新（更快更贵）

ROM 只读存储器

只能读出不能写入，断电不丢失。
用于存放 BIOS、专用子程序、微程序控制器的控制存储器

💾辅助存储器（容量大 · 可靠性高 · 价格低）

  • ① 磁带存储器：顺序存取设备。容量大、便于携带、价格便宜，存取速度慢。
  • ② 硬盘存储器：直接存取设备。分三类：HDD 机械（磁性盘片，信息层次＝记录面→圆柱面→磁道→扇区）、SSD 固态（闪存阵列，寻道时间可忽略）、SSHD 混合（闪存做缓冲）。
  • ③ 磁盘阵列 RAID：用多个小盘替代单个大盘，分块＋交叉＋重聚，改善 I/O 性能与可靠性。8 个级别，下一页详解。
  • ④ 光盘存储器：CD-ROM（只读）· CD-R（WORM，写一次读多次）· CD-RW（可擦写重写）· DVD-ROM（更高容量，4 种物理结构）

⚠️ 两组高频易混：

① DRAM 要刷新、SRAM 不用（SRAM 更快更贵）—— Cache 用 SRAM，主存用 DRAM

② 磁盘标称容量＝格式化容量（约为非格式化容量的 60%~70%），不是非格式化容量

存取地址四元组：驱动器号 · 柱面号 · 磁头（读写头）号 · 扇区号

磁盘计算 · 容量公式 与 平均存取时间

🧮格式化存储容量

存储容量 ＝ n × t × s × b

n＝保存数据的总记录面数　t＝每面的磁道数

s＝每道的扇区数　b＝每个扇区存储的字节数

💡 记法：面 × 道 × 扇 × 字节，四个维度连乘。

⏱️磁盘平均存取时间

Tₐ ≈ Tₛ ＋ T_w ＝ (tsmin＋tsmax)/2 ＋ (twmin＋twmax)/2

存取时间三部分：① 寻道时间（磁头移到目的磁道）＋ ② 等待时间（记录块旋转到磁头下方）＋ ③ 读写时间（可忽略）

📐地址与容量换算（必考小点）

  • 存储容量 ＝ 末地址 − 首地址 ＋ 1（别忘了 +1）
  • 地址线 n 根 → 寻址 2ⁿ 个单元
  • 数据线 m 根 → 字长 m 位
  • 位示图：1 bit 表示 1 个磁盘块状态；磁盘块数 ÷ 8 ＝ 位示图字节数

✏️练一道

内存按字节编址，地址从 A0000H 到 BFFFFH，共多少 KB？

容量 ＝ BFFFFH − A0000H ＋ 1 ＝ 20000H

＝ 2×16⁴ 字节 ＝ 131072 B ＝ 128 KB

⚠️ 易错点：① 忘记 +1；② 十六进制地址换算成十进制时算错；③ 把"按字节编址"看成"按字编址"。

3.2.2 磁盘阵列 RAID · 8 个级别 ⭐

级别技术容量利用率关键特征
RAID 0无冗余、无校验的数据分块最高（N×单盘）I/O 性能最高、空间利用率最高、易管理；故障率高，非冗余
RAID 1磁盘镜像（每个工作盘配镜像盘）50%（N/2）最高安全性；用于存放系统软件、重要文件
RAID 2纠错海明码需增加校验盘大量传输时 I/O 高，不利小批量；实际很少使用
RAID 3 / 4奇偶校验（独立校验盘）≈(N−1)×单盘读快写慢；RAID 3＝位交叉，RAID 4＝块交叉
RAID 5无独立校验盘的奇偶校验(N−1)×单盘校验分布在组内所有盘；独立存取，I/O 可并行；允许坏 1 块
RAID 6独立数据盘＋两个分布式校验(N−2)×单盘允许坏 2 块；性能改进有限、价格昂贵
RAID 7对 RAID 6 的改进（异步高 I/O）—目前最高档次的磁盘阵列
RAID 10RAID 1＋RAID 0（先镜像再条带）N/2×单盘高可靠性＋高性能，性价比较高

口诀：0 条带最快、1 镜像最稳、5 分布校验坏 1、6 双校验坏 2、10 镜像加条带

⚠️ 三大易错：① RAID 1 利用率是 50% 不是 (N−1)；② RAID 5 允许坏 1 块、RAID 6 允许坏 2 块；③ RAID 10 是 先镜像后条带（RAID 1+0），不是先条带后镜像

3.2.3 Cache · 原理与平均访问时间 ⭐

🎯为什么需要 Cache

突破"冯·诺依曼瓶颈"——CPU 与存储系统间的数据传送带宽限制。

在 CPU 和内存之间设置小容量高速的 Cache，靠优化调度改善性能。

🧲依据：程序访问的局部性

时间局部性 — 一个存储单元被访问，则该单元可能很快被再次访问

空间局部性 — 一个存储单元被访问，则邻近单元也可能很快被访问

🧮核心公式（必背）

t₃ ＝ t₁ × h ＋ t₂ × (1 − h)

t₁＝Cache 周期时间　t₂＝内存周期时间　h＝命中率（1−h＝失效率）

教材例题 1：主存 100ns，Cache 10ns，取指命中率 98%，取数命中率 95%，约 1/5 指令需存取一个操作数：

(2%×100 ＋ 98%×10) ＋ 1/5×(5%×100 ＋ 95%×10) ＝ 14.7 ns

简化例题 2：命中率 95%，Cache 10ns，主存 100ns：

T ＝ 0.95×10 ＋ 0.05×100 ＝ 9.5 ＋ 5 ＝ 14.5 ns（对比无 Cache 的 100ns，加速 ≈ 6.9 倍）

⚠️ 易错：① 别把 (1−h) 算成 h；② "指令与数据合一的 Cache"这类双命中率加权题，要分别算取指和取数两部分再相加（别忘了那个 1/5）。

3.2.3 Cache 三种映射方式 ⭐

方式映射规则优点缺点
直接映射主存块固定映射到 Cache 的唯一位置公式：K ＝ I mod C（K＝Cache 块号，I＝主存页号，C＝Cache 块数）容易实现、硬件简单（用 RAM 做 Cache）不够灵活，冲突率高，Cache 空间可能利用不充分
全相联映射主存页可映射到 Cache 的任意一块（用相联存储器做 Cache）灵活、命中率高、无冲突需逐个比较标记，速度很慢；比较电路难实现，只适用小容量 Cache
组相联映射 ⭐直接映射定组号 ＋ 全相联定组内块号公式：J ＝ I mod Q（Q＝Cache 组数）；主存一个组内的页数与 Cache 分组数相同折中方案，映射较灵活，代价小，最常用—

教材例题（组相联的地址位数计算）：Cache 容量 64 块、每块 128 字、每 4 块一组 → Cache 分 64/4＝16 组。主存 4096 页：

  • 每页 128 字 → 主存共 128×4096＝2¹⁹ 字 → 主存地址 19 位
  • 主存分 4096/16＝256 组（2⁸）→ 主存组号 8 位

口诀：直接最简单但冲突多，全相联最灵活但最慢，组相联折中最常用

⚠️ 易错：全相联"速度很慢"是因为要逐个比较标记——不是因为它容量小。

3.2.3 替换算法 与 Cache 写操作

🔁替换算法（Cache 未命中且已满时）

RAND 随机·
FIFO 先进先出·
LRU 近期最少使用

教材点名的三种最常用：随机算法、先进先出算法、近期最少使用算法。

（广义还含 LFU 最少使用、OPT 最优（不可实现）、Clock 时钟）

⚠️ Belady 异常：FIFO 会出现"分配的页框增多，缺页次数反而增加"的异常现象；LRU 不会。

✍️Cache 写操作（保证缓存与内存一致）

① 写直达 Write Through（写通）

写 Cache 时同时写回内存。实现简单、随时保持主存正确；但会增加多次不必要的主存写入，降低存取速度。替换时无需写回。

② 写回 Write Back

只改 Cache，等该块被淘汰时才写回内存。块表里设一个标志位（被修改置 1）。速度快，但主存未随时更新，可能出错。

③ 标记法

每个数据设有效位：进 Cache 置 1；CPU 要修改时只写内存并置 0；读取时测有效位，1 则取 Cache，0 则取内存。

口诀：写直达"边写边同步"慢但准；写回"攒着一起写"快但险；标记法靠有效位开关

3.2.4 网络存储 · DAS / NAS / SAN

🔗DAS 直接附加存储

存储设备通过 SCSI 电缆直接连到服务器，是硬件堆叠，存储操作依赖服务器，不带存储操作系统（也称 SAS 服务器附加存储）。

  • 适用：服务器地理分散难以互连；存储必须直连应用服务器（如某些数据库的"原始分区"）。
  • 局限：传递距离、连接数量、传输速率受限；难扩展；数据读取都要经服务器，压力大；服务器宕机会波及存储。目前基本被 NAS 取代。

→

🌐NAS 网络附加存储

类似专用文件服务器：去掉通用服务器的大部分计算功能，只提供文件系统功能。以数据为中心，存储设备与服务器分离，客户机可直接访问存储设备。

  • 协议：支持 TCP/IP，主要通过 NFS 和 CIFS 进行文件访问。
  • 特点：小文件级的共享存取；支持即插即用，可在网络任一位置建立存储；基于 Web 管理。能经济地解决容量不足，但难以获得满意性能。

🔌SAN 存储区域网络（块级存储）

通过专用交换机将磁盘阵列与服务器连接起来的高速专用子网；不采用文件共享存取，而是块（block）级存储。最大特点：把存储设备从传统以太网中分离出来，成为独立的存储区域网络。

FC SAN

光纤通道。热插拔、高速带宽、远程连接、设备多；最昂贵最复杂（需 FC 适配器、专用交换机、独立布线）

IP SAN

即 iSCSI：用 TCP/IP 封装 SCSI 指令。成本低、配置简单、无距离限制；缺点是存储与网络同一接口、协议开销大

IB SAN

InfiniBand 无限带宽，交换结构 I/O；层次结构（HCA/TCA 接入）；带宽高于 SCSI/FC，支持热插拔

辨析：NAS 走"文件级"，SAN 走"块级"——这是两者最本质的区别，也是最爱考的一句。

3.2.5 虚拟存储 · 3.3 I/O 五种工作方式

🪄虚拟存储 Virtual Storage

把多个存储介质模块（硬盘、RAID 等）集中管理，形成统一管理的存储池（Storage Pool）；物理存储实体与逻辑表示分离，应用服务器只与逻辑卷（虚卷）交互。

  • 按拓扑：对称式（控制设备内嵌在数据传输路径中）｜非对称式（独立于数据传输路径之外）
  • 按原理：数据块虚拟（解决传输冲突与延时）｜虚拟文件系统（解决文件共享安全）
  • 按实现层级：主机级（卷管理软件，成本低）｜存储设备级（厂商控制器）｜网络级（SAN 专用装置，开放性好）

🔀I/O 系统 5 种工作方式（效率递增）

程序控制→

I/O 处理机

① 程序控制方式

分无条件传送（默认就绪，只用于简单开关量）和程序查询（CPU 循环等待，严重影响 CPU 利用率）

② 程序中断方式

CPU 暂停现行程序（保护现场）→ 处理 → 返回（恢复现场）。5 阶段：请求→判优→响应→处理→返回。CPU 无须等待，效率提高

③ DMA 工作方式

主存与外设高速批量数据交换。用 DMAC 控制总线（CPU 放弃总线控制权）。传送前需程序预处理、结束后需中断后处理

④ 通道方式

更独立，可执行通道程序。三种：字节多路（低速设备，字节交叉）· 选择通道（高速，一段时间只服务一台，独占）· 数组多路（两者结合，多子通道）

⑤ I/O 处理机（外围处理机）

有丰富指令系统和独立存储器，基本独立于中央处理机异步工作；除通道全部功能外，还能做码制转换、故障处理、文件管理、诊断等

⚠️ DMA 关键点：① 主存既可被 CPU 访问又可被外设访问；② 地址确定、数据计数由硬件直接实现；③ 主存要开专用缓冲区；④ CPU 与外设并行工作；⑤ 预处理用程序、后处理用中断。

3.3.2 总线 · 分类与特点

🚌总线的两个本质特征

总线是一组能为多个部件分时共享的公共信息传送线路。

共享

总线上可挂接多个部件，各部件交换的信息都通过这组公共线路传送

分时

同一时刻只允许一个部件向总线发送（两个以上同时发会信号冲突）；但允许多个部件同时接收相同信息

在 CPU 与外设一定的情况下，总线速度是制约计算机整体性能的最大因素。

内部总线 vs 外部总线：内部总线＝CPU 内部寄存器之间、ALU 与控制部件之间传输数据；外部总线＝CPU 与内存 RAM/ROM、I/O 设备接口之间通信的通路。

🗂️总线的分类（三种口径）

口径分类

按在系统中的位置机内总线 ｜ 机外总线（与外设接口相连，是外设接口标准）
按总线功用局部总线（ISA 与 CPU 总线之间增加的一级）· 系统总线（系统内部各插板间，如 MCA/VESA/AGP）· 通信总线（系统之间或与其他系统通信）

3.4 指令系统 · 设计要求 与 五类基本指令

🧭指令系统的地位

指令系统是计算机系统中软件与硬件分界面的一个主要标志。

某项功能用硬件还是软件实现，主要考虑三因素：速度、价格、灵活性。
硬件：速度快、价格高、灵活性差；软件：速度慢、价格低、灵活性好。

✅设计四要求

① 完整性 — 通用机应具备的基本指令种类

② 规整性 — 对称性（所有通用寄存器同等对待）＋ 均匀性（不同数据类型/字长/存储设备的指令设置同等对待）

③ 高效率 — 执行快、使用频率高；低频指令少设

④ 兼容性 — 计算机系统的生命力所在

📚五类基本指令

① 数据传送类

最基本。寄存器↔寄存器、寄存器↔主存、主存↔主存。细分：一般传送 / 堆栈操作 / 数据交换

② 运算类

算术 / 逻辑 / 移位（算术移位、逻辑移位、循环移位）。应占比较大（如超 30%），比重过小会影响性能

③ 程序控制类

转移指令（无条件/条件）、程序调用与返回、循环控制。前两类一般机必须具备

④ I/O 指令

主机↔外设信息交换。多用户/多任务下属特权指令，必须在管态下运行

⑤ 处理机控制和调试指令

处理机两状态：管态（主态）与用户态（从态）。用户态只能用一般指令；管态可用特权指令（状态设置、资源管理、进程管理）

⚠️ 高频考点：管态 / 用户态 与 特权指令 的关系 —— 用户态只能用一般指令，特权指令必须在管态下运行。I/O 指令就是典型的特权指令。

3.4.2 CISC 复杂指令系统

🧬CISC 六大特点

① 指令数量众多（100~250 条）

② 使用频率相差悬殊

③ 寻址方式多（5~20 种）

④ 变长指令（译码电路复杂）

⑤ 可直接处理主存单元数据（速度较慢）

⑥ 以微程序控制为主

📉CISC 的三大缺陷（RISC 诞生的原因）

① 80-20 规律：约 20% 的指令使用频率高，占据 80% 的处理机时间；80% 的指令只在 20% 的时间里被用到。

② VLSI 设计负担：指令系统复杂，不利于单片集成；单芯片希望用规整的硬布线控制逻辑而非微程序。

③ 软硬件功能分配问题：复杂指令缩小了高级语言与机器指令的语义差距，但代价是硬件复杂、指令执行周期长。

🎯什么叫 CISC

为增强指令功能，设置一些功能复杂的指令，把原来由软件实现的常用功能改用硬件实现——这就是 CISC。

目标程序优化的两个目的：缩短程序长度（空间开销）＋ 缩短执行时间（时间开销）。

优化目标程序的途径：统计找出使用频率高的指令和指令串 →

  • 高频指令：用硬件加快执行
  • 高频指令串：用一条新指令代替（既省时间又省空间）

💡 80-20 规律是本章最常考的数字：20% 的指令占 80% 时间。

3.4.3 RISC 精简指令系统 ⭐

⚡RISC 七大特点

① 指令数量少 — 只用 LOAD / STORE 两条指令访存，其余都在寄存器间进行

② 寻址方式少 — 通常只支持寄存器、立即数、相对寻址

③ 指令长度固定、格式种类少 — 译码容易

④ 以硬布线逻辑控制为主（组合逻辑）

⑤ 单周期执行 + 流水线技术（LOAD/STORE 例外）

⑥ 优化的编译器 — 不必在相似指令中挑选

⑦ 通用寄存器数量多 — 一般 32 个以上，有的上千

💡 大多数 RISC 采用 Cache 提高取指速度，有的还用两个独立 Cache（指令 Cache ＋ 数据 Cache），取指与取数同时进行互不干扰。

🧮核心思想：P ＝ I × CPI × T

P＝执行程序总时间　I＝指令总条数　CPI＝每条指令平均周期数　T＝周期时间

  • I：RISC 指令更简单，同一源程序编译后 RISC 的 I 更长，但只比 CISC 长 20%~40%（因为 CISC 复杂指令使用频率很低）
  • CPI：CISC 平均 4~10；RISC 多数单周期，CPI 略大于 1 —— 减小 CPI 是 RISC 设计思想的精华
  • T：CISC 的 T 通常是 RISC 的 3 倍左右

结论：RISC 比 CISC 快 3~5 倍

五项关键技术：延迟转移（转移指令后插一条有效指令）· 指令取消（取消则相当于空操作）· 重叠寄存器窗口（划分窗口，与前后过程共用）· 指令流调整（编译器调整指令序列消除相关）· 逻辑实现以硬件为主、固件为辅

💡 实际商品化 RISC 并非纯粹 RISC——还必须辅以少量复杂指令（浮点、十进制运算等），是在 RISC 基础上实现了 RISC 与 CISC 的完美结合。

3.5 多处理机系统 · 与并行处理机的差别

🧩两个基本概念

  • 并行处理机（SIMD）：只有一个控制器＋多个处理单元，所有单元执行同样的运算、数据不同。特别适合矩阵（向量）计算，也叫矩阵/向量/阵列处理机。
  • 多处理机（MIMD）：两个或以上独立的处理机，共享 I/O 子系统，在操作系统统一控制下，通过共享主存或高速通信网络通信，协同求解复杂问题。
  • 多处理机的两个好处：利用多台处理机多任务处理提高速度；利用系统重组能力提高可靠性、适应性和可用性。

⚖️五个维度的差别（根源＝并行性层次不同）

维度并行处理机 SIMD多处理机 MIMD
① 结构灵活性针对数组处理设计，互连通路有限且固定通用性强，结构灵活多变
② 程序并行性操作级并行，识别较易任务级并行，识别难度大
③ 任务派生SIMD，指令本身启动多部件MIMD，需专门指令表示并发关系（并行任务派生）
④ 进程同步受同一控制器控制，自然同步各机执行不同指令，进度不必相同
⑤ 资源分配与调度处理单元数目固定，用屏蔽手段设置不活动数目无固定要求，存在资源分配和进程调度问题

一句记牢：SIMD 是"操作级并行"，MIMD 是"任务级并行" —— 这是所有差别的根源。

3.5.1 多处理机的两种存储方式

🔗共享存储方式

有公共的共享存储器 SM，各处理机通过互连网络共享 SM、传递公共信息与参数。

称为紧耦合系统 / 直接耦合系统。

每个处理机可带局部存储器和 Cache，存储模块可流水工作。SMP 就属于紧耦合系统。

  • ✓ 优点：易管理、程序员无划分数据的负担、编程容易、能加快大程序运行；适合多用户一般应用和分时应用
  • ✗ 缺点：处理机数目有限、扩充困难

按处理机是否同构/对称：常见组合是同构对称式和异构非对称式。

🌐分布式存储方式

每个处理机独占本地存储器 LM，各处理机通过互连网络相连，更像计算机网络的结构。

称为松耦合系统 / 间接耦合系统。

每个处理机带一个 LM 和一组 I/O 设备。MPP 就属于松耦合系统。

  • ✓ 优点：结构灵活、容易扩充
  • ✗ 缺点：难以在处理机间实现复杂数据结构传送、任务动态分配复杂、现有软件可继承性差、需设计新的并行算法

较适合粗粒度的并行计算。

对应关系：共享存储 ＝ 紧耦合 ＝ SMP　｜　分布式存储 ＝ 松耦合 ＝ MPP

3.5.2 MPP 与 3.5.3 SMP

🌊MPP 海量并行处理

按当前标准，具有几百或几千台处理机的任何机器就是 MPP。最重要特点：大规模并行处理。

MPP 采用分布式存储，容易扩展；但各处理机不能直接访问非本地存储器，只能用消息机制共享 → 编程困难、通信开销大。

解决之道：SVM 虚拟共享存储器（又称 DSM 共享分布存储器）

把物理上分散的各处理机的 LM，逻辑上统一编址，形成统一虚拟地址空间 → 用户可当全局 SM 用，紧耦合上的程序可不加修改地运行。

三种实现途径：① 硬件实现（把 Cache 技术扩展到松耦合系统）② 操作系统和库实现（不加专用部件）③ 编译实现（自动转成同步与一致原语）。现有 SVM 多用前两种。

⚖️SMP 对称多处理机

SMP 也称共享存储多处理机。与 MPP 最大的差别在存储系统：SMP 有统一共享的 SM，MPP 每个处理机有自己的 LM。

共享存储三种模型：

  • UMA 均匀存储器存取 — 物理存储器被所有处理机均匀共享
  • NUMA 非均匀存储器存取 — 访问时间随存储字位置不同而变化；SM 物理上分布在各处理机的 LM 上，所有 LM 组成全局地址空间；访问本地快、访问远程慢
  • COMA 只用高速缓存的存储器结构 — NUMA 的特例，把分布主存换成高速缓存，全部 Cache 组成全局地址空间

S2MP 可扩展共享存储多处理机：为解决 SMP 扩展能力问题而提出。本质是 NUMA 结构——存储器靠近处理机而非集中，降低平均访存时延，且存储带宽随处理机数目增加而自动增加（可扩展）。

记牢：SMP＝统一共享 SM（紧耦合）；MPP＝各带 LM（松耦合）；S2MP 本质是 NUMA

3.5.4 互连网络

🕸️互连网络与互连函数

互连网络：连接系统中各处理部件、存储模块、外设，在系统软件控制下使各功能部件相互通信的硬件网络结构。已成为并行处理系统的核心组成部分，对性能/价格比有决定性影响。

六种基本互连函数：

恒等置换（同号一一对应）· 交换置换（第 0 位取反）· 方体置换（第 k 位取反）· 均匀洗牌 Shuffle（地址循环左移一位）· 蝶式置换（最高位与最低位互换）· 位序颠倒（位序整个颠倒）

教材例题：16 个处理机（4 位编码）。

  • 用 Cube₃ 方体置换（k＝3）：11 号（1011）→ 连接 3 号（0011）
  • 用 Shuffle 洗牌：1011 循环左移一位 → 0111，即连接 7 号

💡 性能度量五要素：连接度、延时性、带宽、可靠性、成本。

🔀五种互连方式（按争用程度排）

① 总线方式

最简单；共享总线＋全局存储器。争用最严重

② 交叉开关

把争用降到最低，但连接复杂度最高

③ 开关枢纽

由仲裁单元（处理冲突）和开关单元（完成连接）组成

④ 多端口存储器

把交叉点仲裁逻辑移到存储器去控制；每个存储模块有多个存取端口

⑤ 多级互连网络

是总线方式和交叉开关两者的折中；模块结构、扩展性好；但时延随网络级数上升

⚠️ 两极对比：总线＝争用最严重但最简单；交叉开关＝争用最少但最复杂。多级互连网络是两者的折中。

🔢数字类

  • 系统软件 5 类；存取方式 4 种；性能指标 4 个
  • I/O 工作方式 5 种（程序控制/中断/DMA/通道/I/O 处理机）
  • RAID 8 个级别；RAID 1 利用率 50%；RAID 5 坏 1、RAID 6 坏 2
  • CISC 指令 100~250 条，寻址 5~20 种；RISC 寄存器 32+
  • CISC 的 CPI 4~10；RISC 的 CPI 略大于 1；RISC 快 3~5 倍
  • 80-20 规律：20% 指令占 80% 时间

🔗对应类

  • 冯·诺依曼 5 部件：运算器＋控制器（＝CPU）＋存储器＋输入＋输出（后两个＝外设）
  • Cache 三映射：直接（快/冲突多）· 全相联（灵活/慢）· 组相联（折中/常用）
  • 虚存三方式：页式（内部碎片）· 段式（外部碎片）· 段页式
  • I/O 递增：轮询 → 中断 → DMA → 通道 → I/O 处理机（DMA 不经 CPU）
  • 网络存储：DAS / NAS（文件级）/ SAN（块级）；SAN 分 FC/IP/IB
  • 耦合：共享存储＝紧耦合＝SMP；分布式＝松耦合＝MPP；S2MP＝NUMA

⚖️对比类

  • CISC vs RISC：变长微程序 vs 定长硬布线＋多寄存器＋流水线
  • 写直达 vs 写回：慢但准 vs 快但险
  • 直接映射 vs 全相联：快但冲突多 vs 灵活但慢
  • SIMD vs MIMD：操作级并行 vs 任务级并行
  • 总线 vs 交叉开关：争用最严重 vs 最少（复杂度最高）；多级互连＝折中
  • Cache 用 SRAM，主存用 DRAM

1冯·诺依曼体系结构的五个基本部件中，"运算器 + 控制器"合称为什么？
ACPU（中央处理单元）
B主存储器
C输入输出设备
D总线
五个基本部件：运算器（算术运算 + 逻辑运算）、控制器（取指 · 译码 · 发控制信号）、存储器（存放程序和数据）、输入设备、输出设备。其中运算器 + 控制器 = CPU，另三者是外设。冯·诺依曼体系的核心特征是"程序和数据都用二进制、同样方式存储在同一个存储器里"。
第3章 · 3.1.2 冯·诺依曼体系结构
2按"速度 / 容量 / 价格"三个维度从高到低排序，正确的一组是：
A寄存器 → Cache → 主存 → 辅存：速度递减、容量递增、价格递减
B寄存器 → Cache → 主存 → 辅存：速度递增、容量递减
C辅存 → 主存 → Cache → 寄存器：容量递减
D主存 → Cache → 寄存器 → 辅存：价格递增
存储器层次结构的总规律：越靠近 CPU → 速度越快、容量越小、单位价格越贵；越远离 CPU → 速度越慢、容量越大、价格越便宜。典型配置：寄存器（最快最贵最小）→ Cache（KB 级）→ 主存（MB 级）→ 辅存（TB 级，最慢最便宜最大）。这个层次结构正是冯·诺依曼体系"以数量换速度"思想的延伸。
第3章 · 3.2 存储器系统
3Cache 命中率 h = 0.98，主存访问周期 t = 100ns，Cache 访问周期 t_c = 10ns，则 Cache-主存系统的平均访问时间约为：
A11.8 ns
B10 ns
C100 ns
D98 ns
平均访问时间 = 命中时 t_c + 未命中时概率 × 主存访问时间 = h·t_c + (1−h)·t。代入：0.98×10 + 0.02×100 = 9.8 + 2 = 11.8 ns。看到"命中率"先想到 加权平均公式，这是本章最高频的计算题型。若题目问"加速比"，则是 100 ÷ 11.8 ≈ 8.47。
第3章 · 3.2.3 Cache 原理与平均访问时间
4关于 CISC 与 RISC，下列说法正确的是：
ARISC 指令长度固定、只有 load/store 指令访存、适合流水线；CISC 指令长度可变、指令数量多
BRISC 指令数量多、寻址方式复杂、微程序控制
CCISC 只有 load/store 访存，硬件复杂度低
DRISC 不支持流水线，只能顺序执行
CISC（复杂指令系统）：指令多而复杂、长度可变、微程序控制、寻址方式多、单条指令功能强（如 x86）。RISC（精简指令系统）：指令少而简单、长度固定、只有 load/store 访存、寄存器多、硬布线控制、便于流水线与并行（如 ARM/RISC-V）。⚠️ 判别口诀："只有 load/store 访存"是 RISC 的硬指标；CISC 不具备流水线是因为单条指令跨多个微步骤。
第3章 · 3.4 CISC vs RISC 五维度对比
5指令流水线中的"数据冒险"是指：
A相邻指令因读写同一数据单元、存在依赖关系而必须等待结果
B多条指令同时争用同一总线
C条件转移指令判断失败导致流水线断裂
D流水线中各段耗时不一致
流水线三大冒险：结构冒险（硬件资源冲突，如两条指令同时要同一个寄存器）、数据冒险（后条指令要用前条的结果，可用旁路转发/阻塞解决）、控制冒险（转移指令改变取指路径，可用预测解决）。三者的解决手段不同，别混淆。
第3章 · 3.4.3 RISC 精简指令系统
6多处理机系统中，"MPP"与"SMP"的主要区别是：
AMPP 分布式主存、节点间用消息通信；SMP 共享主存、共享总线或互连网络
BMPP 共享主存；SMP 分布式主存
C两者都是共享主存，只是规模不同
DMPP 由多核组成；SMP 由多台服务器组成
按存储方式分：紧耦合（共享存储） —— SMP（对称多处理机，共享主存+共享总线）、MPP（大规模并行处理机，分布式主存、节点间消息传递）；松耦合 —— 多台独立计算机用网络连接。按处理单元共享方式还有 S2MP（既非纯 SMP 也非纯 MPP 的混合形态）。
