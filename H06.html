第 4 章知识骨架

4.1 计算机网络基础 · 两层划分

计算机网络按数据通信和数据处理的功能可分为两层：

  • 内层 = 通信子网——由结点计算机和高速通信线路组成独立的数据系统，承担全网的数据传输、交换、加工和变换等通信处理工作
  • 外层 = 资源子网——包括计算机、终端、通信子网接口设备、外部设备及各种软件资源，负责全网的数据处理和向网络用户提供网络资源及网络服务

📡通信子网（内层）

管"传"

结点计算机 + 高速通信线路

数据传输 · 交换 · 加工 · 变换

对应 OSI 下三层（物理/链路/网络）

🖥️资源子网（外层）

管"用"

计算机 · 终端 · 外设 · 软件资源

数据处理 · 提供资源与服务

对应 OSI 上三层以上（传输层及以上）

💡 通信的三要素：信源（产生和发送信息）、信宿（接收信息）、信道（通信线路）。

信息在传输中受噪声干扰——电信号受电磁场干扰，光纤信道基本不受电磁场干扰。

4.1.1 奈奎斯特定理与数据速率 ⭐

📏基本概念

  • 模拟信道带宽：W = f₂ − f₁（最低频率到最高频率），由信道物理特性决定
  • 码元：一个数字脉冲；码元速率 B = 1/T（T 为码元宽度），单位波特 Baud，也叫波特率
  • 码元信息量：码元取 N 种离散值 → 一个码元携带 n = log₂N 位（N = 2ⁿ）
  • 数据速率：单位时间在信道上传送的信息量（位数），单位 b/s

奈奎斯特定理（1924，无噪声信道极限波特率）：B = 2W（Baud）

奈奎斯特极限由信道物理特性决定——超过它传送脉冲信号是不可能的；要进一步提高波特率必须改善信道带宽。

🧮数据速率公式

R = B · log₂N = 2W · log₂N

R：数据速率（b/s）；B：波特率；N：码元种类数

⚠️ 数据速率 ≠ 波特率——仅当码元取两个离散值（N=2）时，两者数值才相等。多电平编码可以让一个码元带更多位，数据速率成倍提高。

✏️例题

某信道带宽 W = 3000Hz，采用 4 种离散值（N=4）调制：

  • 最大波特率 B = 2W = 6000 Baud
  • 一个码元携带 log₂4 = 2 位
  • 最大数据速率 R = 6000 × 2 = 12000 b/s

4.1.1 香农定理 + 误码率 + 信道延迟

🔊香农定理（有噪声信道）⭐

C = W · log₂(1 + S/N)

W：信道带宽；S：信号平均功率；N：噪声平均功率；S/N：信噪比

分贝换算：dB = 10 · log₁₀(S/N)

例：S/N = 1000 → 信噪比 = 30dB；反推 30dB → S/N = 1000

教材例题：带宽 3000Hz，信噪比 30dB（S/N=1000）：

C = 3000 × log₂(1+1000) ≈ 3000 × 9.97 ≈ 30000 b/s

与离散值个数无关——只要信噪比给定，最大信息传输量就确定了；实际电话线能到 9600b/s 就很理想

⚠️误码率

P꜀ = Nₑ（出错的位数）/ N（传送的总位数）

计算机通信网络中，误码率一般要求低于 10⁻⁶——即平均每传送 1Mb 才允许错 1b。

⏱️信道延迟

  • 电信号：接近光速 300 m/μs
  • 电缆中：约为光速的 77%，即 200 m/μs 左右
  • 500m 同轴电缆：时延约 2.5 μs
  • 卫星信道：时延约 270 ms

口诀：奈氏管"无噪"，香农管"有噪"；30dB 就是 1000 倍

4.1.2 数据编码 · 模拟编码三调制

📶数字数据 → 模拟信道：三种调制方式

调幅 AM / ASK

载波振幅随基带数字信号变化
例：1 = 有载波输出，0 = 无载波输出

又称幅移键控
容易实现、技术简单，但抗干扰能力差

调频 FM / FSK

载波频率随基带数字信号变化
例：1 用频率 f₁，0 用频率 f₂

又称频移键控
容易实现、技术简单，抗干扰能力较强

调相 PM / PSK

载波初始相位随基带数字信号变化
例：1 = 相位 180°，0 = 相位 0°

又称相移键控
抗干扰能力较强，但实现技术比较复杂

💡 调制 = 波形变换 / 频谱变换：将数字信号的频谱变换成适合模拟信道传输的频谱。三者的差别在"变的那个参量"——振幅、频率、相位。

口诀：幅易差，频较稳，相抗强但复杂

⚠️ 常考对比：抗干扰能力 PM / FSK 强于 AM；实现复杂度 PM 最高。
题干给"抗干扰能力最强/较复杂" → 选调相 PSK。

4.1.2 数字数据编码 ⭐（曼彻斯特必考）

🔣基带传输的编码方式

① 不归零编码 NRZ

低电平 = 0，高电平 = 1
缺点：无法判断每一位的开始与结束，收发双方不能保持同步——必须另用一个信道传送同步信号

② 曼彻斯特编码 ME ⭐

用电平的跳变表示；每一比特的中间均有一个跳变——既作时钟信号又作数据信号
电平从高到低跳变 = 1；从低到高跳变 = 0

③ 差分曼彻斯特编码 DME

每比特中间的跳变仅作同步之用；每比特的值由开始边界是否发生跳变决定
开始边界无跳变 = 1；有跳变 = 0

④ 多电平编码

码元可取 M=2ⁿ 个电平之一，每个码元代表 n 位 → 数据速率大于波特率，提高频带利用率；但抗噪声特性不好

⚡编码效率

曼彻斯特 / 差分曼彻斯特：每位中间都有跳变 → 波特率是数据速率的两倍

传 10Mb/s 数据需要 20MHz 脉冲；100Mb/s 网络需要 200MBaud，硬件成本是 100MBaud 的 5~10 倍

  • 优点：无须另发同步信号
  • 缺点：编码效率低（50%）
  • ⑤ 4B/5B 编码：用 5bit 二进制码代表 4bit 数据

→ 编码效率 4/5 = 80%，提高效率、降低电路成本

口诀：曼彻斯特"高到低是 1"，差分"不跳是 1"；效率 50%，4B/5B 是 80%

4.1.3 差错控制 · 分类与奇偶校验

🌪️差错的两大来源

随机错误（热噪声）

电子热运动产生，时刻存在、频谱宽、幅度小
信噪比越高差错越少
影响个别位

突发错误（冲击噪声）

外界电磁干扰（打雷闪电、电焊机）
持续时间短而幅度大
引起一个位串出错

💡 突发性差错影响局部，随机性差错断续存在、影响全局（教材原话）。

✅奇偶校验 + 校验和

奇偶校验（最常用的检错方法）：在 7 位 ASCII 代码后增加一位，使码字中 1 的个数为奇数（奇校验）或偶数（偶校验）。

传输后若一位（甚至奇数个位）出错，接收端按同样规则就能发现。

方法简单实用，但只能对付少量的随机性错误。

校验和（为检测突发性位串错误）：把数据块中每个字节当作二进制整数，按模 256 相加，得到的和作为校验字节发送；接收端同样求和比较。

实现时可对累加器取 2 的补码——不出错时接收端加完后累加器中是 0

口诀：热噪声随机、冲击噪声突发；奇偶防随机，校验和防突发

4.1.3 海明码 ⭐（必考计算）

🧮海明距离与纠错能力

海明距离：一个码字变成另一个码字时必须改变的最小位数。

若任意两个码字的海明距离为 d：

  • 所有 ≤ d−1 位的错误都可以检测出来
  • 所有 < d/2 位的错误都可以纠正

要纠正它就要用比仅仅检测它多一倍的冗余位

校验位个数 k 的下界（必背）：

m + k + 1 ≤ 2ᵏ

m：数据位；k：校验位（冗余位）；n = m + k

📐编码方法（海明方案）

  • ① 校验位位置：海明把奇偶校验分配在 1、2、4、8 等 2 的幂位置上，其他位放数据
  • ② 校验位参加规则：把位号写成二进制：位号二进制中第 i 位为 1 的，就参加第 2^(i−1) 位校验

例：6 = 110 → 参加 2、4 位校验，不参加 1 位；9 = 1001 → 参加 1、8 位校验

  • ③ 校验位取值：按偶校验（或奇校验）计算各校验位
  • ④ 纠错：接收端按同样规则重算各校验位，出错校验位的位号相加 = 错误位置

例：2 号位和 4 号位错 → 2 + 4 = 6，错在 6 号位

教材例：传送信息 1001011（m=7），k=4 → 满足 m+k+1=12 ≤ 2⁴=16；数据放 3、5、6、7、9、10、11 位，1、2、4、8 位留作校验位，按偶校验得码字 10110010011。若 6 号位出错 → 校验发现 2、4 号位错 → 2+4=6 立即定位。

4.1.3 循环冗余校验码 CRC

♻️CRC 的特点与原理

循环码：任一有效码字经过循环移位后得到的码字仍然是有效码字。

CRC 是一种循环码，检错能力很强，而且容易用硬件实现，在局域网中有广泛应用。

  • 多项式除法原理（模 2 运算）：
  • 数据多项式：m 个数据位 = m−1 阶多项式的系数（例：00101011 → x⁵+x³+x+1）
  • 生成多项式：G(x)，对应移位寄存器反馈回路
  • 发送码字：F(x) = xᵏ·D(x) + R(x)（R(x) 是余式）
  • 接收端：对 F(x) 计算校验和应为 0；若 E(x) 也能被 G(x) 整除则有差错而检测不到

🔢模 2 运算 + 标准生成多项式

模 2 运算：加法和减法一样，都是异或运算（1+1=0，0+1=1，−1=1）。

用 x 乘多项式 = 把系数左移一位。

📋国际标准生成多项式

CRC-CCITTx¹⁶+x¹²+x⁵+1

CRC-16x¹⁶+x¹⁵+x²+1

CRC-12x¹²+x¹¹+x³+x²+x+1

CRC-32常用于局域网

💡 CRC 由 k 位移位寄存器 + 异或门 + 反馈回路实现（可按 CCITT-CRC 标准生成 16 位校验和）；寄存器初始化为 0，数据右向左逐位输入，输完数据再输 k 个 0。

4.2 网络协议三要素 + OSI 概述

网络体系结构 = 计算机网络的各层及其协议的集合。

网络协议：用于规定信息的格式以及如何发送和接收信息的一套规则。

① 语法

控制信息或数据的结构和格式

② 语义

需要发出何种控制信息、完成何种动作以及做出何种应答

③ 同步（时序）

事件实现顺序的详细说明

OSI/RM 开放系统互连参考模型（ISO 推出）：共分 7 层，层与层之间在逻辑上对等通信，最后由物理层实现真正的通信；每一层完成相应功能，下一层为上一层提供服务——把复杂的通信过程分成多个独立的、比较容易解决的子问题。

💡 分层的好处：不同机器上的同等功能层之间采用相同的协议；同一机器上的相邻功能层之间通过接口进行信息传递。

背景：ARPANET 分组交换网的实践经验表明，复杂的计算机网络结构最好是层次型的。

第 18 题循环冗余校验码（Cyclic Redundancy Check ，CRC）是数据通信领域中最常用的一种差错校验码，该校验…

循环冗余校验码（Cyclic Redundancy Check ，CRC）是数据通信领域中最常用的一种差错校验码，该校验方法中，使用多项式除法（模2除法）运算后的余数为校验字段。若数据信息为1100，生成多项式为 X3+X+1（即1011），则 CRC 编码是（）。

  • A 1100010
  • B 1011010
  • C 1100011
  • D 1011110
显示答案与解析

答案：A

按照CRC标准计算流程，最终将原始信息1100与校验余数010拼接，得到完整CRC编码1100010。

- 🟡 支撑：时延（单向）：≤150ms（优秀 <100ms），否则对话有明显延迟感

- 🟡 支撑：丢包率：≤1%（语音），超过 3% 音质明显劣化
