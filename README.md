# 阿甘系分 · 48 小时冲刺手册

系统分析师备考手册 —— 按学时拆解，内容讲透、图解落地、页面内直接答题。

## 目录

| 页面 | 内容 |
|---|---|
| `index.html` | 手册总览 · 48 学时总目录 |
| `H01.html` | 第 1 学时 · 绪论与备考总纲 |
| `H23.html` | 第 23 学时 · 软件需求工程（一） |
| `H45.html` | 第 45 学时 · 论文写作专项 |

## 使用

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

**快捷键**：`/` 搜索 · `T` 深/浅色 · `F` 专注模式 · `-` `+` 字号 · `P` 答下一题 · `0` 回顶部

**功能**：章节练习题（即时判分+ 解析 + 回溯）· 全站错题本 · 4 级侧边目录 · 全文搜索 · 打印优化
